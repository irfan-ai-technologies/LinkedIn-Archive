We shipped six Model Context Protocol servers this year. The biggest lesson: treat every tool definition like a public API contract, because an agent will use it in ways you didn't anticipate. Second: log everything, because debugging an agent's tool-call sequence after the fact is the only way to understand failures. Third: keep tools narrow and composable rather than building one giant do-everything tool. #MCP #AgenticAI #Engineering
